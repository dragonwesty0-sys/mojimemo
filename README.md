# もじメモ

日本語の文字数カウンター。HTML・CSS・JavaScriptの静的サイトです。ローカルではリポジトリのルートで `python3 -m http.server --directory .` を実行して確認できます。

## Cloudflare Pages

Git連携で新規リポジトリの `main` を本番ブランチに指定し、フレームワークはなし、ビルドコマンドは空欄、出力ディレクトリは `.` にします。公開先は https://mojimemo.pages.dev/ です。正規URLとサイトマップはこの公開先に設定済みです。

トップページに Google AdSense のコードを設置しています。広告配信の審査状況は AdSense の「サイト」で確認できます。
